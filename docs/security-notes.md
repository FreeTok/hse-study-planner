# Статический анализ

Для статического анализа я подключил Semgrep. Он запускается в GitHub Actions отдельным job и проверяет JavaScript-код по локальному конфигу `.semgrep.yml`.

## Что проверяется

Сейчас добавлены три правила:

- `javascript-no-eval` - запрещает `eval`, потому что строка не должна выполняться как код;
- `javascript-no-inner-html` - предупреждает про запись через `innerHTML`, потому что так легко получить XSS;
- `javascript-no-document-write` - предупреждает про `document.write`, потому что он плохо контролирует вставку HTML.

В текущей реализации я использую `textContent`, `createElement` и JSON API, поэтому эти правила не должны находить проблем.

## Как запустить локально

Если Semgrep установлен локально:

```bash
semgrep scan --config .semgrep.yml .
```

Если Semgrep не установлен, можно хотя бы быстро проверить те же опасные конструкции через `rg`:

```bash
rg -n "eval\(|\.innerHTML\s*=|document\.write\(" src public test
```

Если команда `rg` ничего не выводит, значит эти конкретные конструкции в коде не найдены.
